# C++课程项目：明日方舟风格 2D 塔防

用 C++ 和 **SFML 3** 图形库，从零做一个《明日方舟》风格的
2D 塔防小游戏。

## 明日方舟是什么？

《明日方舟》(Arknights) 是鹰角网络出品的一款塔防手游。核心玩法：敌人会一波波地沿着地图上的
道路，从「出怪口」走向你要守护的「基地」；你在有限的部署费用下，把不同职业的「干员」（近战
重装、远程狙击、法术术师……）摆到网格上，用他们**阻挡并攻击**敌人，赶在敌人闯进我方基地之前把它们
清光。每个干员的费用、血量、攻击方式、攻击范围都不一样——**把谁放在哪、先放谁**，就是策略所在。

## 本课程项目的目标是什么？

本项目分为以下几个阶段，分层次利用你在C++课程的各个章节上学到的知识：
1. 敌人的移动（条件、循环、数组）
2. 干员的部署（函数）
3. 战斗逻辑（模块化开发、面向对象设计）
4. 索敌逻辑（类，运算符重载）
5. 干员技能与增益（继承与多态）
6. 自由开发（文件读写与Vibe Coding）

项目的每个阶段的工作任务将被详细说明，各个子任务分为建议（要求）进行手动编程的，和推荐进行Vibe Coding的。
除最后一部分之外，项目的主要评分点都落在手动编程的部分上。
项目的每个阶段除需要提交的代码之外，你还需要提供一份报告（PDF）文件，介绍你的工作情况和总结感悟。

## 安装依赖（第一次配置，只做一次）

本项目可以运行在**Windows**和**MacOS**上。

编译本项目**只需要两样**：**CMake** + **一个 C++ 编译器**。SFML 本体 + 它的文字依赖
（freetype / harfbuzz / sheenbidi）都已随仓库自带（`SFML-3.1.0/` 与 `deps/`），构建时静态编译
进程序——**全程不需要联网**。按你的系统照下面一步步做（做完一步再做下一步）。

### Windows

**① 装编译器（MinGW-w64 的 g++）**
1. 打开 <https://winlibs.com/> ，往下滚到 **“Release versions”**；在 **UCRT runtime** 那栏找 **Win64**，
   下载它的 **Zip archive**（文件名形如 `winlibs-x86_64-...-ucrt-...zip`）。
2. 把下载的 zip **解压到一个不含空格、不含中文的目录**——建议直接解压到 `C:\`，会得到文件夹 **`C:\mingw64`**。
3. **把 `C:\mingw64\bin` 加进 PATH 环境变量**（这样命令行才能直接用 `g++`）：
   - 按 `Win` 键，搜索 **“环境变量”** → 打开 **“编辑系统环境变量”** → 点右下角 **“环境变量(N)…”**；
   - 在下半部分 **“系统变量”** 里找到 **`Path`** → 双击 → **“新建”** → 填入 `C:\mingw64\bin` → 连点 **“确定”** 关掉所有窗口。

**② 装 CMake**
1. 打开 <https://cmake.org/download/> ，在 **“Binary distributions”** 下载 **Windows x64 Installer**（`.msi`）。
2. 双击安装，安装途中**务必勾选** `Add CMake to the system PATH for all users`（否则命令行找不到 `cmake`）。

**③ 验证**（改过环境变量后，**必须新开一个** PowerShell / 命令行窗口，旧窗口不会生效）：
```bat
g++ --version
mingw32-make --version
cmake --version
```
三条都能打印出版本号，就配好了。

### macOS

**① 装编译器（Xcode 命令行工具，自带 clang + make）**
打开 **“终端”(Terminal)**，运行：
```bash
xcode-select --install
```
在弹窗里点 **“安装”**，等它装完即可（**无需配置 PATH**，系统会自动就绪）。

**② 装 CMake（用 Homebrew 最省事）**
1. 装 Homebrew：打开 <https://brew.sh> ，把首页那条安装命令**整行复制**到终端运行、按提示走完；
   若装完时提示要把 Homebrew 加入 PATH，照它最后给出的两行命令再粘贴执行一次即可。
2. 装 CMake：
   ```bash
   brew install cmake
   ```

**③ 验证：**
```bash
clang --version
cmake --version
```
都能打印出版本号，就配好了。

## 构建 & 运行

可执行文件叫 **`ark`**，生成在**项目根目录**。请在项目根目录下运行它
（因为贴图、字体都是相对路径）。

**项目提供了两个脚本，用途不同：**

- **`build`**（`build.bat` / `build.sh`）＝ **完整构建**：先用 `cmake` 配置，再编译，最后运行。**第一次**、或删过 `build/` 文件夹后，用它。
- **`compile`**（`compile.bat` / `compile.sh`）＝ **只重新编译**：跳过配置，直接增量编译再运行。**改完 `main.cpp` 后**用它，通常几秒钟。
  > 注意：`compile` 不做配置，所以**必须先成功跑过一次 `build`**（否则还没有配置好的 `build/` 文件夹）。

**Windows**
```bat
build.bat        :: 第一次：配置 + 编译 + 运行
compile.bat      :: 之后改了代码：快速重编译 + 运行
```

**macOS / Linux**
```bash
./build.sh       # 第一次：配置 + 编译 + 运行（若提示无权限：chmod +x build.sh compile.sh，或用 bash build.sh）
./compile.sh     # 之后改了代码：快速重编译 + 运行
```

或手动（不用脚本，等价于上面）：
```bash
cmake -S . -B build      # 首次配置；Windows 需加 -G "MinGW Makefiles"
cmake --build build      # 编译（之后改了代码，只重复这一行即可）
./ark                    # 运行；Windows 上是 ark.exe
```

> 首次构建会把自带的 SFML 源码静态编译一遍，约几分钟，**仅第一次**；之后用 `compile` 很快。


## 关于本分支

本分支对应项目的第 2 个阶段：**干员的部署**（配合“函数”一章——从本阶段起，你可以在 `main()` 之外编写自己的函数）。

具体任务见 [`INSTRUCTIONS.md`](INSTRUCTIONS.md)。打开 `main.cpp` 后，从“第一部分 · 游戏数据 + M2 任务”开始阅读并完成 5 个任务函数；后面的运行框架和渲染引擎本阶段可以跳过。

运行代码后，窗口底部多了一条**部署栏**：点选一张干员卡片，再点地图上的格子，就能把这名干员部署下去
——重装 / 近战干员放在“地面”（`#`），远程干员放在“高台”（`P`）；每次部署要消耗**部署费用（DP）**，
点击已部署的干员会弹出撤退按钮。本阶段的编程任务，就是编写与“部署”相关的几个函数
（例如判断某格能不能放、扣费并放下干员、撤退并返还费用等）。
